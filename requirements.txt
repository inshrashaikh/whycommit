# Whycommit prerequisites
#
# This file lists the plain-text prerequisites for building and running
# Whycommit. The actual npm dependencies live in package.json and are installed
# with `npm install` (the exact versions are pinned in package-lock.json).

# Required runtime / development tools
Node.js >= 18 (LTS recommended)
npm >= 9
VS Code ^1.85.0 (see the engines field in package.json)
git >= 2.30

# Optional: local model (no API key, nothing leaves your machine)
Ollama (https://ollama.ai) with a model such as llama3.2

# Optional: API keys for remote providers
Anthropic (Claude)
OpenAI
Google Gemini
Groq
OpenRouter
OpenCode Zen

# Optional: packaging a .vsix
@vscode/vsce (install globally or run with npx)
